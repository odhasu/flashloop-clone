# Flashloop website preview

Published site: https://odhasu.github.io/flashloop-clone/

This repository contains the static frontend export of the Flashloop reference clone, including local images, fonts, videos and HLS segments. The original source repository and its history remain private.

Primary navigation includes all observed tabs except Super Agent, including Faceless Studio. Authentication, payments, generation and email delivery require the original service; this preview recreates the frontend.

Built from source commit `9d5c225a811993222266df83f2016cf95f773866` on 29 October 2026. ESLint, TypeScript, production export and ten tests passed before publication.
