What is DeepSeek V4 Flash?

DeepSeek V4 Flash is the smaller DeepSeek V4 model, released as an open-weight preview on April 24, 2026, with 284B total parameters and 13B active per token.

DeepSeek built it for fast, economical responses with reasoning close to V4 Pro, and its new attention design keeps the 1M-token context cheap to run. It accepts text only. Super Agent runs that April preview build through third-party hosts. DeepSeek has since released newer builds, including V4 Flash 0731 and V4.1 Flash, and the official results on this page are for the preview.

What you can do with DeepSeek V4 Flash

  • 284B total parameters, 13B active per token

  • Reasoning close to V4 Pro, according to DeepSeek

  • New attention design for cheaper 1M-token context

  • Open weights under the MIT license

How to prompt DeepSeek V4 Flash

  • Use it for many quick text tasks in a row, where speed matters most.
  • Describe images in words, since it can't read attachments that aren't text.
  • Turn reasoning on for anything that needs a plan; it starts at off.

Where DeepSeek V4 Flash fits best

  • High-volume prompt writing

  • Quick text chat

  • Summaries of long text

  • Fast drafts you will refine later

Questions about DeepSeek V4 Flash

Which DeepSeek V4 Flash build does Super Agent use?

The April 2026 preview, which Super Agent reaches through third-party hosts. DeepSeek has since shipped V4 Flash 0731, V4.1 Flash and V4.1 Flash 1017. Its own API now serves V4.1 Flash as deepseek-flash and, for now, routes the old deepseek-v4-flash name there too.

What is DeepSeek V4 Flash built for?

Fast, economical text work. DeepSeek says its reasoning comes close to V4 Pro and that it performs comparably on simple agent tasks.

Can DeepSeek V4 Flash read images?

No. It accepts text only, and Super Agent tags it Text only in the model picker.

Which reasoning levels does DeepSeek V4 Flash support?

Super Agent lists off, medium, high and extra high, starting at off. DeepSeek documents the April preview with three modes: non-thinking, high and max. Its current API offers low, high and max and maps medium and extra high to high.
