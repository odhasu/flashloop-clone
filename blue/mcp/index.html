Add Flashloop as a custom MCP plugin, then use it in the conversation you already have open.

Open ChatGPT

  1. Add a custom MCP server

    In ChatGPT on the web, open Plugins. Select the plus button, then Add custom MCP server. Workspace permissions and security restrictions apply.

  2. Enter the connection

    Name the plugin Flashloop. Under Connection, paste this server URL. Review the permission warning before creating and installing the plugin.

    Get the server URL

  3. Authorize, then ask

    Complete the Flashloop sign-in and authorization when prompted. Type @ in the prompt box, select your installed Flashloop plugin, and describe what you want to create.

A few useful answers.

What is Flashloop MCP?

MCP is the Model Context Protocol, an open standard that lets compatible AI assistants use external tools. Flashloop's remote MCP service brings its creative tools into an assistant's conversation.

Which assistants can I use?

This guide covers ChatGPT, Claude, Claude Code, Codex and Cursor, plus a generic remote MCP configuration. Support for remote servers, authorization and individual tools depends on your client, plan and workspace permissions.

Do I need an API key?

The existing Flashloop connection uses browser-based account authorization rather than an API key pasted into this website. Review the requested access and authorize only a server you trust.

Does this website host the MCP server?

No. This is the connection guide for the existing service at mcp.flashloop.ai. It does not create a separate backend, sign you in automatically or grant an assistant access to your account.

What can I ask it to create?

Flashloop's source guide describes images, videos, reusable characters and voiceovers. The exact tools, models, parameters and file formats available to you are the ones your connected assistant discovers.

Can I use my own references?

Ask your assistant which image, video or audio references the selected tool accepts. Upload through the client's supported flow; do not assume an assistant can read a local file path. Reference limits vary by model.

Can I choose a model and control spending?

Yes: specify your preferred model and ask the assistant to check whether it is available. Request a credit estimate and set a budget before approving a generation. This static guide cannot read your account balance.

Can I edit media or generate a batch?

Ask the assistant to inspect the available editing and batch tools first. Supported inputs, operations and batch limits vary by server and tool. Confirm the supported limit before scheduling multiple tasks.

Where do finished results appear?

The Flashloop source guide says creations are saved to your Flashloop library. Your assistant can return the result or its download link according to the connected tool and the client's supported interface.

How does pricing work?

Connecting uses your Flashloop account. Generations use the service's normal credits and model pricing. Check your plan, the selected model and a fresh estimate before approving work; no bonus credits are promised here.
