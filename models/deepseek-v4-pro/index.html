What is DeepSeek V4 Pro?

DeepSeek V4 Pro is the large DeepSeek V4 model, released as an open-weight preview on April 24, 2026, with 1.6T total parameters and 49B active per token.

DeepSeek built it for agentic coding, broad world knowledge and reasoning in math, STEM and code, and at launch called its maximum-effort mode the best open-source model available. Its hybrid attention needs 27% of the per-token inference compute and 10% of the KV cache of DeepSeek V3.2 at 1M tokens of context. It accepts text only. Super Agent runs the April preview build through third-party hosts; DeepSeek has since released V4 Pro 0813, which its own API now serves under the same name.

What you can do with DeepSeek V4 Pro

  • 1.6T total parameters, 49B active per token

  • Max-effort mode named the best open-source model at launch, per DeepSeek

  • Leads open models on world knowledge, trailing only Gemini 3.1 Pro, per DeepSeek

  • Hybrid attention keeps its 1M-token context efficient

How to prompt DeepSeek V4 Pro

  • Paste long source text and ask it to pull out what matters.
  • Turn reasoning on for hard tasks; Super Agent starts it at off.
  • Describe visual references in words, since it reads text only.

Where DeepSeek V4 Pro fits best

  • Synthesizing large amounts of text

  • Long multi-step automation

  • Hard reasoning in math and code

  • Analysis of long documents

Questions about DeepSeek V4 Pro

Which DeepSeek V4 Pro build does Super Agent use?

The April 2026 preview. DeepSeek released the V4 Pro GA build (V4-Pro-0813) on August 13, 2026, and its own API now serves it as deepseek-v4-pro. The preview reaches Super Agent through third-party hosts.

How is DeepSeek V4 Pro different from V4 Flash?

Both share the same architecture. V4 Pro is much larger (1.6T total, 49B active parameters versus 284B and 13B) and aimed at harder reasoning, while V4 Flash is built for speed.

Can DeepSeek V4 Pro read images?

No. V4 Pro reads text only, and the model picker shows a Text only tag for it.

Which reasoning levels does DeepSeek V4 Pro support?

The picker offers off, medium, high and extra high and starts at off. DeepSeek's card for the April preview lists non-thinking, high and max modes. DeepSeek's own API, which now serves the newer build, maps medium and extra high to high.
