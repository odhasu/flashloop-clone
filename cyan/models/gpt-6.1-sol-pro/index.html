What is GPT-6.1 Sol Pro?

GPT-6.1 Sol Pro is GPT-6.1 Sol with OpenAI's pro reasoning mode switched on.

OpenAI documents pro as a setting on the same model ID, meant for difficult tasks that need more model work and can tolerate higher latency and token usage. Answers take longer and use more tokens than the same request on standard GPT-6.1 Sol. OpenAI hasn't published benchmark results for pro mode, so the official results on the GPT-6.1 Sol page are the closest reference.

How to prompt GPT-6.1 Sol Pro

  • Ask for one well-defined result per message. Pro mode works best on a single hard problem.

  • Try the question on GPT-6.1 Sol first and switch to Pro only if the answer falls short.

Questions about GPT-6.1 Sol Pro

Is GPT-6.1 Sol Pro a different model from GPT-6.1 Sol?

No. OpenAI serves the same model with its reasoning mode set to pro, which makes it work longer before answering.

When should I use GPT-6.1 Sol Pro?

For difficult questions where you can wait longer for the answer. OpenAI keeps standard mode as the default and offers pro for tasks that need more model work.

Why is GPT-6.1 Sol Pro slower?

Pro mode does more work per request, so it uses more tokens and takes longer than the same request on GPT-6.1 Sol.

Are there official benchmarks for GPT-6.1 Sol Pro?

No. OpenAI hasn't published results for pro mode. Its launch results cover GPT-6.1 Sol across its standard effort levels, and you can find them on the GPT-6.1 Sol page.

Which reasoning levels does GPT-6.1 Sol Pro support in Super Agent?

Low, medium, high, extra high and max. Thinking is always on, and Super Agent starts it at low.
